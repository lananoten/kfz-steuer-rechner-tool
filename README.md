# Kfz-Steuer-Rechner (Tool)

Einfacher **Kfz-Steuer-Rechner für Pkw** als einzelne HTML-Datei – ohne Build, ohne Abhängigkeiten. Einfach `index.html` im Browser öffnen.

## Was wird berechnet?

Die jährliche Kfz-Steuer für Pkw mit Erstzulassung nach dem 01.07.2009, nach der offiziellen Formel:

**Kfz-Steuer = Hubraum-Anteil + CO₂-Anteil**

- Hubraum-Anteil: je angefangene 100 cm³ → 2,00 € (Benziner) bzw. 9,50 € (Diesel)
- CO₂-Anteil: je Gramm über dem Freibetrag (95 g/km seit 2014) → 2,00 €, seit 2021 gestaffelt bis 4,00 €

Die benötigten Werte stehen im Fahrzeugschein: Feld **P.1** (Hubraum) und Feld **V.7** (CO₂).
